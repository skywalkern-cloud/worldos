### 1.2 四处偏差（前三处可接受，第四处要动）

**① techGreen 的有效权重在同一次改动里从 0.2 涨到 0.3（+50%）。**

这个 +0.179 是今天全表第三大的单项贡献，而它的 2/3 来自两个截断常数（见 §5）。

**② riskAppetite 的「全球」名不副实，且 0.4 权重给的是一个因子两票。**
`vix` 与 `fearGreed` 都是美股权益恐慌度量，日相关性长期 0.7~0.9，今天同向（−0.254 / −0.755）。

**判定：可接受，但必须改标签为「美股风险偏好」或把 `extras` 里 vix/f&g 的相关系数标出来。这是我 11-27 方案里就有的毛病，不是执行偏差。**

**③ 维度内是等权平均，没有任何指标级权重。**
`avg = Σ(score×α)/Σα`，即「1 个指标的极端值 = 该维 1/n」。6 项维度上是 17%，**3 项维度上是 33%**。
这是我在方案里的默认假设，但在 `liquidity/riskAppetite/resource/techGreen` 四个 3 项（含 2 项）维度上它变得危险：
今天的 `resource` 就是 1 个指标（沪铜 −1.0）决定了整维 −0.333。
**判定：有条件接受——不要求加指标级权重（那会让模型变成又一个黑箱），但必须做 P0-1 的饱和披露，让「1/n = 33% 由常数贡献」可见。**

**④ `fxExternal` 内部双计美国 10Y（P0-2，必改）。** 详见 §2、§3。

## 2. `creditSpread` → 「中美 10Y 利差」并入「汇率与外部」：**改名对了，并入的位置不对**

**改名：完全符合原意。** 我 11-27 的原话就是「名不副实、跟信用无关」。现在 `name='中美10年利差'`、
`caliberNote='中美10年期国债收益率之差(bp)；非信用利差'`，`short='中美10Y利差'`——口径、名称、数据源三处一致，没有留旧词。✅

**并入 `fxExternal`：方向对，但制造了一个我自己没看见的共线。**

事实核对（`fetch_worldos_data.get_credit_spread`）：

```
creditSpread = 美国国债收益率10年 − 中国国债收益率10年   （单位 bp）
今日：4.94 − 1.60 ≈ 3.34 → 334bp
```

而 `fxExternal` 的第四个成员是 `usBond10Y`（4.94%）。**即：美国 10Y 既是独立一项，又是利差的一项。**
后果是符号同向的重复计价：

| 事件 | `usBond10Y` 打分 | `creditSpread` 打分 | 维度内净效果 |
|---|---|---|---|
| 美债 10Y 上行 50bp（中债不动） | 变差 | 变差（利差走阔） | **同一件事罚两次** |
| 中债 10Y 下行 50bp（美债不动） | 不变 | 变差 | 罚「中国宽松」——这与 `liquidity` 的判断方向相反 |

第二行是更要命的问题：**中国降息导致的利差走阔，被记成「外部压力」，而它在 `liquidity` 里本该是加分。**
今天 `usBond10Y` 的 score 恰好 0.0（4.94 落在双向中性区 3.0~5.0），所以**当日双计贡献为零**——
这也是为什么报告里看不出问题。**但它距离开中性区只剩 6bp（5.00% 即越界）**：
也就是说 P0-2 不是「未来的风险」，是「随时会启动、且启动时正好是最该看清的时候」。

**判定：改名通过；归属「不合格，必须改」。** 三个可选修法（请 PM 拍一个，我不替你定）：

- (a) `usBond10Y` 降 `reference_only`，`fxExternal` 变 3 项 → `required=3` 全有效，更脆（见 §4）。**不推荐，除非同步做 (c)。**
- (b) `creditSpread` 改成**变化量**（Δ20 日，bp）而不是水平值，`usBond10Y` 保留水平值。两者承载的信息就正交了（一个是「相对变化的外部压力」，一个是「绝对贴现率水位」）。但 Δ 需要序列，而 `usBond10Y` 目前**没有 series**（`data/history/series/` 只有 4 个 A 股代理 + usdcnh）→ 属 P2。
- (c) **收编中债 10Y**：把 `中国国债收益率10年` 从 `creditSpread` 的算子里拆出来，作为 `liquidity` 的第 4 项；`fxExternal` 保留 `creditSpread`（利差，含外部相对定价）+ `usdbond10Y` 降为参考。
  这条**一箭三雕**：消掉双计、给 `liquidity` 补第 4 项（解决 §4 的脆度）、且数据源现成（`ak.bond_zh_us_rate()` 已经在同一请求里取到了，零新增外部依赖）。**我推荐 (c)。**

## 3. `usBond2Y`/`5Y` 降为只展示、`10Y` 进 `fxExternal`：**会丢期限结构，但丢掉的部分今天不值钱；恢复方式绝不能是「把 2Y/5Y 转正」**

**先答「丢没丢」：丢了，而且是彻底丢了——不只是「不打分」，是「没有任何地方算斜率」。**
现在 2Y/5Y/10Y 三个值都在页面上，但库里没有任何一个字段是 `10Y−2Y` 或 `5Y−2Y`。
意味着**倒挂（inversion）这个最有用的单一宏观信号，当前系统在数学上无法产生**，只能靠人眼看三张卡片脑补。
今天是 4.69 / 4.74 / 4.94 → 2s10s = +25bp、5s10s = +20bp，正常陡峭，没有信号可丢。
所以**今天的损失是 0，未来的损失是「倒挂那天没人知道」。**

**这是否值得恢复：值得，但排在 P2，理由是数据不具备而不是设计不需要。**
`pct_rank` 是我们唯一敢用的相对打分法（不拍绝对值），而它需要 20~60 个历史观测；
`usBond2Y/5Y/10Y` **全都没有 series**（我核过 `data/history/series/`）。现在硬做一个斜率打分，
只能回到 `(L,T,H)` 拍数字——那正是 `evPenetration`/`carbonPrice` 今天出问题的病根。**用一个病去治另一个病，不做。**

**如何恢复而不重复计价（关键）：斜率必须是一个「派生指标」，不是「把 2Y/5Y 转正」。**
正确的形状是：

```
新增 usCurve2s10S（派生，scoring_method=pct_rank，transform=raw）
  取值 = 美国10Y − 美国2Y
  归属 = riskAppetite（它是风险偏好的经典度量，不是汇率）
同时：usBond2Y / usBond5Y / usBond10Y 一律保持 reference_only（只展示）
      fxExternal 里的 creditSpread 走 (b) 方案改 Δ 口径后，与斜率不再共线
```

判据：**同一根收益率曲线，只允许出现一个「打分」的自由度。**
2Y 水平被 `fedRate` 吸收、10Y 水平被 `creditSpread`（外部相对定价）吸收、**斜率单独算一项**，
三者正交；如果同时给 2Y/5Y/10Y 三个水平打分，就是把一条曲线拆成三票，重演 `lmeIndex`+`沪铜`。

**判定：当前切法可接受（低成本、无误导）；恢复时按上面的「派生一项 + 水平全展示」做，不许转正 2Y/5Y。**

## 4. `liquidity` 只剩 3 项、T4 要求全有效：**单看 liquidity 可忍，但它是「系统性脆度」的样本，整体不可接受**

先把它单独算清楚：

- `liquidity` 的 0.8 权重 = 标尺的 **14.3%**。三项 `lpr`（月）/`dr007`（日）/`m2`（月）。
- 最容易断的是 `dr007`：日频、黄线 5 天、红线 10 天。**春节/国庆这种 8~10 天长假，DR007 会直接 α=0 → valid=2 <3 → 整维归零。**
- 它断掉的当日后果：`normalized` 从 −0.102 变 **−0.121** → **「持有」直接掉「减仓」**（见 §5 的 drop-liquidity 行）。
  也就是说：**一个日频数据源的假期空窗，可以单独翻转今天的大盘信号。**

但真正的问题不是 liquidity 一个维度。**T4 的 `n≤3 → 全部有效` 规则，是为 6 维世界（维度 4~8 项）写的；
搬到 8 维以后，有 4 个维度撞在这条线上：**

| 维度 | 项数 | required | 全年「全有或全无」的权重 | 极易同时失效的场景 |
|---|---|---|---|---|
| liquidity | 3 | 3 | 0.8 | 长假（DR007） |
| riskAppetite | 2 | 2 | 0.4 | 美股休市 / CNN 页面改版（**两个源同市场，相关性失效，同时挂的概率高**） |
| resource | 3 | 3 | 0.5 | 商品源（油/气/铜三个都是实时报价类，同一个抓取故障会一起挂） |
| techGreen | 3 | 3 | 0.3 | 乘联会月更 + 碳市场日更，任一断 |
| **合计** | | | **2.0 / 5.6 = 35.7%** | |

**35.7% 的标尺是「一票否决」的。** 我实测了「四个薄维度全灰」这一情形（模拟一个长假）：

```
drop 全部四个薄维度 → normalized = −0.1085，coverage 0.643（仍 > 0.6，照常给建议）→ 信号「持有」但只剩 0.0005 余量
```

即：即使按规则「照常出分」，结论也已经贴在线上；而系统只会标一句「部分维度缺失·参考」，
**不会告诉你「这个分数是在 64% 的标尺上算出来的，而且刚好卡在边界」。**

**判定：不可接受，但不是「liquidity 该加第 4 项」这么简单——是「四个薄维度都要松一口气」。**
最小改动、按性价比排序：

1. **`liquidity` 补第 4 项：中债 10Y 收益率**（数据源现成，见 §2 方案 (c)）。→ 4 项、required 降为 2，脆度立解，还顺带把 fxExternal 的双计拆了。
2. **`riskAppetite` 允许 1/2 有效**，但必须给维度打 `single_indicator=true` 标记，且 `weight_effective` 按 `valid/active` 收缩（0.4 → 0.2）。理由：VIX 单独一个也有信息量，fearGreed 是它的冗余；宁可权重减半，不要整维消失。
3. **`resource` / `techGreen` 保持 3/3**（这三项的绝对值打分本来就是同源、同故障模式，缺一项时确实宁可不给分），但把「缺项归零」写进 `validity_report` 的 `dimension_dropped` 并在页面上显式提示（见 §6）。

顺带一条口径建议：`required_valid_count` 对 n=2 的维度返回 2（全有效），这没问题；
但 **n=3 的维度一律 3/3 太硬**。建议改成 `n=3 → 2`（配 `single_indicator` 式的信心标记），
这样 `liquidity`/`resource`/`techGreen` 都不再一票否决，而「2/3 出分」的可信度损失由标记承担，不由刻度承担。

### 5.2 你点名的两维：是不是「慢变量/代理主导」复发？——**是，但真正的病根不是「慢」，是「截断饱和 + 等权平均」**

**`techGreen +0.597`** = (1.0 − 0.208 + 1.0)/3。两个 +1.0 的来历：

| 指标 | 值 | 打分参数 | 得分 | 性质 |
|---|---|---|---|---|
| evPenetration | 67.4% | POSITIVE (20, 40, 60) | **+1.0** | 值 > H，**永久封顶**。月频慢变量 |
| carbonPrice | 97.0 | POSITIVE (30, 60, 90) | **+1.0** | 值 > H，**永久封顶**。就是工单 §0 点名「越阈值永久 +1」那个 bug |
| renewEnergyInvest | 1117 | POSITIVE (800, 1200, 1600) | −0.208 | **唯一真的在动的一项** |

所以这一维今天的真实信息量 = 一项（`renewEnergyInvest`，−0.208）。**它名义上 +0.597，实际上约等于 −0.07 加两个常数。**
诊断修正：这不是「慢变量主导」——`carbonPrice` 是日频，不慢；病根是 **`L/T/H` 绝对阈值 + `±1.0` 硬截断**：
值一旦越界，指标就退化成常数，而「常数」在等权平均里仍然占 1/3 的票。
**这类指标在最需要它的时候（行情极端）恰好失去分辨力，这是绝对阈值打分的宿命，不是慢变量的错。**

**`riskAppetite −0.505`** = (−0.254 + −0.755)/2。VIX 与 F&G 是同一因子的两个读数，
0.4 权重 × 两票 = 给「美股 fear」7.1% 的标尺；若只留 VIX，本维 = −0.254、贡献 −0.102。
**这一个是标准的「代理指标主导」复发**：我把一个潜变量写成了两个指标，还给了它们等权。

**这两维合起来的问题不是「分数不准」，是「它们恰好撑住了结论」——见 5.3。**

### 5.3 刀锋证据：单维剔除敏感性

对产物逐维剔除重算（严格按当前 `calc_ias` 的再归一化口径）：

| 剔除维度 | normalized | 信号 | 覆盖率 |
|---|---|---|---|
| —（全量） | −0.1020 | 持有 | 1.000 |
| economic | −0.0698 | 持有 | 0.821 |
| **inflation** | −0.1487 | **减仓** ★ | 0.821 |
| **liquidity** | −0.1208 | **减仓** ★ | 0.857 |
| **fxExternal** | −0.1203 | **减仓** ★ | 0.875 |
| sentimentA | −0.0637 | 持有 | 0.839 |
| riskAppetite | −0.0710 | 持有 | 0.929 |
| resource | −0.0794 | 持有 | 0.911 |
| **techGreen** | −0.1416 | **减仓** ★ | 0.946 |

**8 个维度里有 4 个，掉一个就翻档；其中 `techGreen` 是 8 维里我最不信的那一维。**
换句话说：**今天的「持有」不是因为八维共识偏中性，而是因为 4 个不可信的维度（含 2 个常数制造的正贡献）刚好把分数按在 −0.109 之内 0.007。**

假设检验（每行只改一个假设，其余冻结）：

| 假设 | normalized | 信号 |
|---|---|---|
| 现状 | −0.1020 | 持有 |
| `techGreen` 两项饱和归零（按「不携带信息」处理） | −0.1377 | **减仓** |
| `resource` 沪铜饱和归零 | −0.0723 | 持有（余量变宽松） |
| 两者同时归零 | −0.1079 | 持有（余量 0.0011） |
| `riskAppetite` 只算 VIX | −0.0841 | 持有 |
| `usdcnh` 掉一档到 0 | −0.1176 | **减仓** |
| 四个薄维度全灰（长假） | −0.1085 | 持有（余量 0.0005） |

**结论：这个信号的「方向」（轻微偏负）是稳的；「档位」（持有/减仓）不稳，且不稳的来源是两个已知待修的打分 bug
一正一负刚好抵消（−0.20 / +0.17）。** 11-28 的 `持有` 不能作为「8 维结构校准正确」的证据——
它只证明了「两个 bug 的净效应 ≈ 0」，是巧合，不是校准。

### 5.4 另外两处我认为不可信但你没问的

- **`inflation +0.113` 的符号假设需要复核。** `ppi` 走 POSITIVE `(−5, 0, 3)`，即「再通胀 = 好，通缩 = 差」。
  这是**我们从未明写、但被代码默认的一个立场**；而 5.7% 的 PPI 已经越过 `H=3.0`，所以它永远给 +1.0。
  如果批次 C 的「PPI 方向」修正把方向翻过来，`inflation` 从 +0.113 → −0.287，**normalized 直接 −0.102 → −0.173，稳掉「减仓」**。
  这不是猜测，是可算的：**一个尚未修的 bug，单独就能决定今天的档位。**
- **`shanghaiCopper −1.0` 与「老板持洛钼」的设计理由互相矛盾。** 我 11-27 用「中国定价 + 老板持洛钼」
  来论证保留沪铜打分，但 `BIDIRECTIONAL (40000, 55000, 75000, 90000)` 的含义是「铜价过高 = 成本压力 = 差」。
  对持有铜矿股的人来说，铜价 92,550 是**利好**，模型却给 **−1.0**。
  要么设计理由写错（保留它只是为了「看得见」，不是为了「当利好计分」），要么极性写错。
  **至少要在 caliberNote 里写明「本项按成本/通胀压力方向计分，不作为铜矿股盈利的直接读数」**，否则老板看到 −1.0 会读反。

## 6. 降级态：会静默退化，且**今天就差一档**——必须加看门狗

先确认事实（报告 §7 + 代码）：

- 降级判据单一（`NO_SCORE_WHEN_SOURCE_DEGRADED={'usdcnh'}`），降级 → `score=null`、`fxExternal` 3/4 有效、
  `insufficient_data=false`、维度照常出分。页面有徽标「降级·不计分」、`caliberNote` 有「在岸参考价」。
- `validity_report.source_degraded` 会把降级源列出来（今天为空）。

**问题一：这个降级在「结论层」是隐形的。** 徽标只挂在 `usdcnh` 那张卡片上；
`ias.signal = 持有` 这个大字旁边没有任何提示说「本次结论少了一项」。
用户看的是顶部信号，不是 36 个指标卡片里的某一张。**这就是静默退化的定义：信息在，但不在决策路径上。**

**问题二（更要命）：降级足以翻转今天的信号。** `usdcnh` 从 +0.5 掉到「不计分」，
`normalized` 从 −0.1020 → −0.1218（报告 §4 已自认）。也就是说：

> **今天离岸源挂掉 ⇒ fxExternal 变成 3 项 ⇒ 信号从「持有」变「减仓」，而页面只是给一张小卡片加了个徽标。**

这不是理论风险，是**在任何一天都可能发生、且发生时无人知晓**的单点翻转。D7「宁缺勿错」的方向我完全同意，
但「不计分」不等于「不报警」——**宁缺勿错，不能等于宁缺勿说。**

**看门狗：该加，而且加在 `meta.ias` 层，不是加在卡片层。** 最小集合（全部是产物字段，不动打分规则）：

```jsonc
meta.ias = {
  ...
  "boundary_margin": 0.0070,          // normalized − 最近阈值（带符号）；<0.02 即「刀锋」
  "fragile_inputs": ["inflation","liquidity","fxExternal","techGreen"],  // 逐维剔除会翻转信号的清单
  "degraded_inputs": [{"key":"usdcnh","weight_impact":0.7,"reason":"onshore_fallback"}],
  "confidence": "low"                 // 任一打分项降级/缺失，或 boundary_margin<0.02 → low
}

validity_report.dimension_dropped = [...]  // 整维被剔时显式列出 + weight_lost + 剔除前该维分数
```

以及一条运维级（这条不属于本批，但要登记）：**同一指标连续 N 轮降级 → 告警**。
`usdcnh` 是离岸价，在岸回退如果在节假日持续 3 天以上，`ratio` 的 MA120 会开始被代理值污染——
D7 已经把它挡在打分之外，这就够了；但**「连续降级」这个状态本身需要一个计数器**，否则我们会连着两周拿 3/4 的维度出结论而毫无察觉。

**判定：必改（P0-3 的一部分）。** 具体地说：**「降级不计分」是对的；「降级不出声」是错的。**

## 8. 最担心的一条

**今天的「持有」不是判断，是两个已知 bug 的算术残差。**

`techGreen` 的 +0.179（其中 2/3 是 `carbonPrice` 的截断 +1.0）与 `resource` 的 −0.167（几乎全部是
`shanghaiCopper` 的截断 −1.0）在 5.6 的标尺上互相抵消到 0.006 以内，刚好把 normalized 按在
「持有/减仓」这条线的内侧 0.007 处。**批次 C 只要修好其中任何一个方向，结论就不是「持有」了。**

八维结构本身是好的、忠实的、比我 11-27 的方案更严谨（阈值量纲统一 + 派生 IAS_SCALE 是真进步）。
但它现在把一个**不可信的输入**包装成了一个**看起来很确定的输出**——`➖ 持有 / 40-60%`。
**这个包装比结构本身危险**：结构错了我们会怀疑，包装得太好我们就不会。

所以我的验收口径是：结构通过；**在 P0-1/P0-3 落地前，页面上那个大字必须降级为「持有（低置信·余量 0.007·含 2 项饱和输入）」。**
